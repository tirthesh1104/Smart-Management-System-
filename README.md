# Smart Campus - Curriculum & Activity Management System

A comprehensive educational platform for managing curriculum, tracking attendance, scheduling events, and facilitating communication between students, teachers, and parents.

## Features

### For Students
- **Dashboard Overview** - Real-time stats on attendance, upcoming events, live classes, and exams
- **Attendance Tracking** - Geofenced check-in with QR code and face scan verification
- **Live Classes** - Join scheduled live sessions with teachers
- **Exam Portal** - Take exams with automatic grading
- **Event Management** - View and register for campus events
- **AI Learning Planner** - Personalized learning paths generated by AI
- **Progress Tracker** - View grades and assignment progress
- **Leave Applications** - Request and track leave status
- **File Manager** - Access shared study materials
- **Notifications** - Real-time alerts for important updates

### For Teachers
- **Daily Attendance** - Mark attendance manually or via face scan/QR code
- **Live Class Management** - Schedule and conduct live sessions
- **Exam Management** - Create, edit, and grade exams
- **Leave Request Management** - Approve or reject student leave applications
- **Attendance Records** - View and filter historical attendance data
- **Student Overview** - Monitor student access and behavior status
- **Event Creation** - Create and manage campus events
- **Announcements** - Post important notices for students/parents
- **Calendar View** - Visualize schedules and events

### For Parents
- **Child Progress Monitoring** - View attendance and academic performance
- **Event Updates** - Stay informed about campus activities
- **Announcements** - Receive school-wide and targeted communications

## Tech Stack

- **Frontend**: React 19, TypeScript, Vite
- **Styling**: Tailwind CSS
- **State Management**: React hooks with localStorage persistence
- **AI Integration**: Gemini API for learning path generation

## Run Locally

**Prerequisites:** Node.js

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```
